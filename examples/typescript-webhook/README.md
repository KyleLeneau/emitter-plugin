# Typescript Webhook

Extremely minimal Http webhook for testing. Just run `npm install && npm run dev` to start the server, then configure Emitter plugin to use `http://localhost:8000/webhook` as the URL (you might need to change the host for your network).

This example using [nestjs](https://nestjs.com/) backend framework with [fastify](https://docs.nestjs.com/techniques/performance) http server stack for best performance.
