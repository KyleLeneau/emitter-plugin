# Contributing

Pull requests are welcome and appreciated!

Please provide as much detail as possible on what you are trying to accomplish and any issues you are running into.

Also, please include any relevant code, error messages and example scripts with any changes.

## Setup

dotnet (https://github.com/dotnet/sdk) is required to build (mac or windows supported).

## Testing

You can invoke the tests with dotnet command:

```bash
dotnet test
```

Please also install the plugin on your local system and do testing.
